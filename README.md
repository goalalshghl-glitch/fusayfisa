# فسيفساء | FUSAYFISA

مكتبة مراجع شخصية بسيطة: احفظ صورك وملفاتك على جهازك، وارجع إليها متى شئت، حتى دون إنترنت.

## الاستخدام
- **إضافة:** اضغط «إضافة» ← اختر صورة أو ملف ← حفظ. الاسم والملاحظة اختياريان.
- **عرض:** اضغط على أي مرجع لفتحه بحجم أكبر، وعدّل الاسم والملاحظة مباشرة (تُحفظ تلقائياً).
- **من داخل المرجع:** مفضلة، مشاركة (إن دعمها الجهاز)، نسخ، حذف.
- **البحث:** يبحث في الاسم والملاحظة.
- **المجموعات (اختيارية):** «+ مجموعة» في الرئيسية، ثم اختر المجموعة من داخل أي مرجع.

## الخصوصية والتخزين
- لا تسجيل دخول، ولا خادم، ولا قاعدة بيانات خارجية، ولا رفع لأي جهة.
- كل شيء محفوظ في متصفحك على جهازك (IndexedDB)، ويبقى بعد إغلاق الموقع أو تحديث الصفحة.
- لا مزامنة بين الأجهزة؛ كل جهاز له مكتبته.
- يعمل دون إنترنت بعد أول فتح (Service Worker).
- على iPhone: أضف الموقع إلى الشاشة الرئيسية ليبقى محفوظاً بشكل أفضل.
