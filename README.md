# فسيفساء | FUSAYFISA

> «كل فكرة لها صورة، وكل صورة لها مكان».

مكتبة صور ومراجع شخصية تعمل بالكامل داخل المتصفح: تحفظ صورك محلياً، وتنظّمها في أقسام وتصنيفات ومجموعات، وتعمل دون إنترنت بعد أول زيارة. التجربة قريبة من Pinterest في سهولة التصفح، مع تنظيم أدق.

## المزايا

- **الأقسام:** السيارات (صفحة مستقلة لكل سيارة مع الخارجية والداخلية والتعديلات والجنوط والألوان)، الديني (صور ونصوص مع مصادرها)، المساحة الخاصة (الأنمي، والصور البشرية النسائية للبالغات فقط)، وإمكانية إنشاء أقسام جديدة من الإعدادات.
- **التصنيفات قابلة للتعديل** من الواجهة: إعادة التسمية، الإضافة، الحذف، الترتيب، ومصطلح البحث الإنجليزي لكل تصنيف.
- **إضافة الصور:** من الملفات أو معرض الجوال أو الكاميرا، عدة صور دفعة واحدة، مع الاسم والوصف والكلمات المفتاحية والملاحظات ورابط المصدر والقسم والتصنيف والمجموعات والمفضلة.
- **الحفظ المحلي في IndexedDB:** الملف الأصلي + صورة مصغرة + البيانات، وتبقى بعد إغلاق المتصفح.
- **عرض Masonry** متجاوب دون قص أو تشويه، مع تحميل تدريجي للصور.
- **عارض الصور:** السابق/التالي (أزرار، أسهم لوحة المفاتيح، سحب بالإصبع)، تعديل، حذف بتأكيد، مجموعات، تنزيل، نسخ رابط المصدر وفتحه.
- **البحث المحلي:** بالاسم والوصف والكلمات المفتاحية والقسم والتصنيف والمجموعة واللون الغالب (يُستخرج تلقائياً من الصورة)، مع توحيد الحروف العربية وتجاهل التشكيل.
- **البحث الخارجي عبر Pinterest:** يبني عبارة بحث من القسم والتصنيف وخيارات التصفية ويفتح صفحة النتائج. لا يجلب الصور آلياً.
- **المفضلة والمجموعات:** إنشاء وتعديل وحذف وغلاف وترتيب.
- **الإعدادات:** الوضع الليلي/النهاري، حجم الشبكة، إظهار الأقسام، كلمة مرور المساحة الخاصة، تصدير/استيراد نسخة احتياطية، مساحة التخزين، طلب التخزين الدائم، حذف الصور، إعادة الضبط.
- **العمل دون إنترنت** عبر Service Worker وCache API، وقابل للتثبيت كتطبيق (Web App Manifest).

## بنية الملفات

```
index.html            هيكل الواجهة والأيقونات
style.css             الهوية البصرية والتجاوب والوضع الليلي
app.js                منطق التطبيق (قاعدة البيانات، الصفحات، البحث، الحفظ)
manifest.webmanifest  بيانات التثبيت كتطبيق
sw.js                 التخزين المؤقت والعمل دون اتصال
icons/                أيقونات التطبيق
.nojekyll             لتجاوز معالجة Jekyll في GitHub Pages
```

## بنية البيانات (IndexedDB: `fusayfisa`)

| المخزن | المحتوى |
|---|---|
| `images` | البيانات الوصفية لكل عنصر: `id, kind (image/text), name, description, keywords[], notes, sourceUrl, sectionId, subjectId, categoryId, attrs{}, favorite, color, width, height, size, mime, fileName, text{}, createdAt, updatedAt` |
| `files` | الملف الأصلي `{id, blob}` |
| `thumbs` | الصورة المصغرة `{id, blob}` |
| `sections` | الأقسام `{id, name, type, icon, order, desc, pinPrefix, allowText, builtin}` |
| `categories` | شجرة التصنيفات `{id, sectionId, parentId, name, en, order, filters?, adultOnly?}` |
| `subjects` | السيارات `{id, sectionId, name, coverId, createdAt}` |
| `collections` | المجموعات `{id, name, description, coverId, imageIds[]}` (الترتيب = ترتيب المصفوفة) |
| `settings` | الإعدادات `{key, value}` |

إضافة قسم جديد لا تحتاج تعديل الكود (من الإعدادات). لإضافة مجموعة خيارات تصفية جديدة عدّل `FILTER_SETS` في `app.js` واربطها بتصنيف عبر الحقل `filters`.

## التشغيل محلياً

الموقع ملفات ثابتة، لكن Service Worker يحتاج خادماً (لا يعمل بفتح الملف مباشرة):

```bash
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

## النشر على GitHub Pages

1. ارفع الملفات إلى جذر مستودع على GitHub.
2. من **Settings › Pages** اختر **Deploy from a branch**، والفرع `main`، والمجلد `/ (root)`.
3. بعد دقيقة يصبح الموقع متاحاً على `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`.

كل المسارات نسبية، لذلك يعمل الموقع وService Worker داخل مسار المستودع دون تعديل.

## الصيانة والتحديث

- بعد تعديل أي ملف من ملفات الواجهة، ارفع رقم `CACHE_VERSION` في `sw.js` (و`APP_VERSION` في `app.js`) ليحصل المستخدمون على النسخة الجديدة؛ سيظهر لهم تنبيه «تحديث الآن».
- لا تغيّر `DB_VERSION` إلا عند تغيير بنية المخازن، وأضف منطق الترحيل في `onupgradeneeded`.

## ملاحظات مهمة وحدود تقنية

- **الخصوصية والنشر:** موقع GitHub Pages متاح للعامة إذا كان المستودع وإعدادات النشر تسمح بذلك. لكن صورك **لا تُرفع** إلى أي مكان؛ تبقى في متصفحك على جهازك فقط.
- **المساحة الخاصة** ميزة إخفاء بسيطة داخل الواجهة وليست حماية أمنية: كلمة المرور تُخزن مشفّرة بـ SHA-256 محلياً، لكن الكود يعمل في المتصفح ويمكن فحص البيانات. لا تخزن فيها معلومات سرية.
- **لا مزامنة:** البيانات خاصة بالمتصفح والجهاز الحاليين. استخدم «تصدير نسخة احتياطية» لنقلها إلى جهاز آخر.
- **حذف البيانات تلقائياً:** قد يحذف Safari على iPhone بيانات المواقع غير المستخدمة لفترة طويلة. ثبّت الموقع على الشاشة الرئيسية، وفعّل «التخزين الدائم» من الإعدادات، وصدّر نسخاً احتياطية.
- **Pinterest:** لا توجد واجهة رسمية عامة تسمح بجلب نتائج البحث آلياً، لذلك يفتح فسيفساء صفحة النتائج فقط. احفظ الصور المسموح لك بحفظها يدوياً ثم أضفها، واحترم حقوق أصحابها.
- **المحتوى الديني:** فسيفساء لا يأتي بنصوص جاهزة ولا يتحقق من النصوص. عند إضافة آية يُلزم باسم السورة ورقم آية صحيح ضمن عدد آياتها، وعند إضافة حديث يُلزم بذكر المصدر، وتُعرض «العبارات العامة» منفصلة بوضوح عن النصوص الشرعية.
- **الخطوط** تُحمَّل من Google Fonts وتُخزن بعد أول زيارة؛ وإن لم تتوفر يُستخدم خط النظام.
- صيغة HEIC تعمل فقط في المتصفحات التي تدعمها (مثل Safari)؛ معرض iPhone يحوّلها عادة إلى JPEG تلقائياً.
